# Graph evidence model

Status: Accepted; Phase 3 proof complete

Date: 2026-09-16

## Decision

Every semantic edge references one or more immutable evidence records containing source path, locator, digest, extractor/version, observation, registry confidence/trust and safe metadata. Deduplicate relationships, not their explanations.

## Consequences and proof obligations

No source bodies, credentials or environmental values enter evidence. Explorer exposes evidence alongside edges.
